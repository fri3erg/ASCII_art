# maddy-lilies 🌷

Virtual flowers for Maddy.

A message writes itself on screen in pink handwriting: *"ehy maddy, per te 👉👈"*. Then it breaks up into
tiny golden sparks, and a bouquet of lilies grows where it was. The flowers keep swaying after that, so you
can leave it open as long as you like.

On a phone the greeting goes onto four short lines and the bouquet is zoomed out a little, so everything
fits on the screen.

## putting it online

On Vercel, import the repo as a new project, set **Root Directory** to `projects/maddy-lilies`, choose
**Other** as the framework, and deploy.
