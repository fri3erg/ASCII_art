# esn ⭐

The ESN star on its own, no text, drawn with letters. The eight bars fly in one by one and click into
place, then the star breathes gently, a band of light sweeps across it, sparks shoot off the tips in each
bar's colour, and every ten seconds it slowly turns all the way round. It's a solid star with real thickness, so
when it turns you see its edges, and from behind it shows its back.

The star is drawn from code (eight rounded bars around an octagon, in ESN's cyan, magenta, green and
orange), so there are no image files and it stays sharp at any screen size. The logo belongs to the
Erasmus Student Network.

## putting it online

No photos here, so a normal Vercel import works: set **Root Directory** to `projects/esn`, framework
**Other**. Or run `npx vercel --prod` from this folder. Adding `?t=10` to the address jumps 10 seconds in.
